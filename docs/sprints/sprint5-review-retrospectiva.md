## Review

### O que foi concluído
- BET-23 - Como administrador, quero criar contas de acesso ao backoffice para os funcionários da clínica, para que possam faze login e gerir as operações
- BET-422 - Como administrador, quero associar funcionários a serviços específicos, para que os agendamentos sejam feitos apenas com funcionários habilitados
- BET-25 - Como funcionário, quero fazer login com as minhas credenciais para aceder às áreas e funcionalidades correspondentes ao meu perfil
- BET-26 - Como funcionário, quero recuperar a minha palavra-passe caso a tenha esquecido para voltar a aceder à minha conta
- BET-421 - Como administrador, quero eliminar funcionários que já não trabalham na clínica, para manter a lista atualizada
- BET-394 - Como funcionário, quero eliminar a ficha de um animal quando necessário, para remover registos duplicados ou incorretos.
- BET-27 - Como funcionário, quero editar os meus dados de perfil para manter a minha informação de contacto atualizada


### O que não foi
- BET-420 - Como administrador, quero editar os dados de um funcionário existente, para manter a informação atualizada - movida para Sprint 6 (IN REVIEW)
- BET-43 - Como funcionário, quero gerar uma fatura no final de um serviço interno para o cliente possa efetuar o pagamento - movida para Sprint 6
- BET-37 - Como funcionário, quero ver os agendamentos do dia/semana/mês para organizar o trabalho da clínica - movida para Sprint 6
- BET-34 - Como funcionário, quero registar um agendamento presencialmente no backoffice para um cliente, quando ele se desloca à clínica ou contacta telefonicamente - movida para Sprint 6
- BET-41 - Como funcionário da clínica, quero registar a chegada de um animal para um serviço agendado para iniciar o processo e informar que o cliente já entregou o animal - movida para Sprint 6
- BET-42 - Como funcionário, quero registar a conclusão do serviço e a saída do animal para libertar o funcionário e a sala para o próximo agendamento e gerar a fatura - movida para Sprint 6
- BET-471 - Como funcionário, quero registar a não comparência de um cliente a um agendamento confirmado, para que o horário seja libertado e o histórico fique correto - movida para Sprint 6
- BET-36 - Como funcionário, quero alterar a data/hora de um agendamento existente, para ajustar à agenda do cliente/funcionário - movida para Sprint 6
- BET-35 - Como funcionário, quero cancelar uma marcação que já não vai acontecer, para libertar o horário - movida para Sprint 6
